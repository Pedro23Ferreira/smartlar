# SmartLar — App de Orçamentos

App web da **SmartLar Dedetização e Desratização** e da **SmartLar Serviços & Segurança**.
É um único arquivo `index.html`: abre no navegador do celular ou do computador e funciona sem internet.

## Como usar
1. Abra o `index.html` no navegador (ou publique no GitHub Pages).
2. Vá em **Mais → Empresa, perfis e padrões** e confira dados, logo, preços e textos.
3. Crie o orçamento, gere o PDF (Imprimir → Salvar como PDF) e envie pelo WhatsApp.

> Os dados ficam **no aparelho** (localStorage). Faça backup em **Mais → Backup**.
> Nunca suba backups, fotos ou dados de clientes para este repositório.
